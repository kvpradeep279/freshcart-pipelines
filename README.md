# FreshCart Pipelines

End-to-end Data Engineering assignment covering:

1. Git and CI/CD
2. FreshCart ELT using Snowflake
3. Machine Learning pipeline using Mage
4. Event streaming using RabbitMQ

## Project Structure

- `elt/` - FreshCart ELT pipeline
- `iris_project/` - Mage Iris ML pipeline
- `stream/` - RabbitMQ dispatcher and driver
- `tests/` - Automated tests
- `.github/workflows/` - CI/CD configuration

## Technologies

Python, Git, GitHub Actions, Snowflake, Mage, RabbitMQ.
